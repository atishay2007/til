# Daily Commit Workflow Checklist

1. Check `git status` and `git diff` before staging so stray temp files stay out.
2. Group changes into small, single-purpose commits (`add ...`, `fix ...`, `test ...`).
3. Keep `.gitignore` updated for `node_modules/`, `__pycache__/`, `.env`, and `.DS_Store`.
4. Run unit tests or linters before committing code changes.
